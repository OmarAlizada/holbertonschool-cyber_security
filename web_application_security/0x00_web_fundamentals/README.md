# 0x00. Web Fundamentals

## Description

This project introduces the fundamentals of web application security. It covers how the web works, the evolution of Web 1.0, 2.0, and 3.0, front-end and back-end communication, stateful vs stateless design, structured vs unstructured data, the OWASP Top Ten web application security risks, and bug bounty programs.

## Learning Objectives

- How the Web works
- Examples of Web Applications
- Web 1.0 vs Web 2.0 vs Web 3.0
- PWA - Progressive Web Applications
- How the Front-End communicates with the Back-End
- Stateful vs Stateless: What's the difference?
- Structured vs Unstructured data
- Web Application Security Risks
- Bug Bounty Programs

## Requirements

- All scripts tested on Kali Linux
- Scripts are exactly two lines long
- First line: `#!/bin/bash`
- Files end with a new line
