# Burp Suite Fundamentals

This repository contains the completion of all 6 Burp Suite fundamental tasks from the Holberton Cyber Security curriculum.

## Completed Tasks

- **Task 0**: Basic Burp Suite setup and configuration
- **Task 1**: Additional Burp Suite fundamentals
- **Task 2**: Further Burp Suite exercises
- **Task 3**: Exploring the Repeater Tool - Login credential testing using default router credentials (admin/admin, admin/password, etc.)
- **Task 4**: The Intruder's Path to Hidden Profiles - Automated brute-forcing to discover hidden user profiles
- **Task 5**: Deciphering Tokens with Sequencer - Session token randomness analysis and hijacking
- **Task 6**: Decoder Tab - Base64 Bearer Token manipulation for privilege escalation

## Flag Files

Each task contains a flag file documenting the successful completion:
- `0-flag.txt` - Task 0 flag
